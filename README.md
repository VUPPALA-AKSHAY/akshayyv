# Vuppala Akshay — Portfolio

🌐 **Live:** https://vakshay.vercel.app

Personal portfolio of **Vuppala Akshay**, AI & Frontend Developer from Hyderabad.
Built with Next.js, React, Tailwind CSS and a sprinkle of AI.

## Highlights

- **Paint-my-portfolio** — a 42-color Blossom picker that re-themes the whole page live (background, accents, headings), with Reset
- **6 AI projects** — HireLens, Hermes outreach agent, RAG chatbots, AI debugger, calendar agent
- **Experience, education & certifications** timeline
- **GitHub activity** heatmap + contribution cards
- **theSVG brand icons** across the skills sections
- Dark mode first, fully responsive

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
```

## Other scripts

```bash
npm run build    # production build
npm run start    # serve production build
npm run lint
```
